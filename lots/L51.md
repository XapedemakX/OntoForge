# L51 : manuel du développeur (docs/dev, fr/en)

Pilotes : devback (expert-dev-backend, Opus) et devfront (expert-dev-frontend, Sonnet). Relecture : croisée entre les deux, puis doc (vérification contre le code), puis humain (humaniseur). Origine : Jerem, 23/11 : « documenter de manière exhaustive toutes les fonctionnalités, comment c'est codé, comment ça interagit, quelle librairie, pour qu'un dev humain puisse reprendre » ; bilingue, sur GitHub (pas dans l'appli).
