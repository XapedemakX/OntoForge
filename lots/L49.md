# L49 : bonnes pratiques d'ontologie — fiche complète, dépréciation, version sémantique, métadonnées

Pilote : w3c (expert-w3c, modèle Opus). Origine : pistes tirées d'un guide de bonnes pratiques (cycle de vie, fiche d'entité, SemVer), « lance le tout » de Jerem du 16/11. Aucun contenu du guide (document client) n'entre dans le dépôt. Rapport : `journal/L49/rapport.md`.

## Objectif
1. **Fiche complète.** Nouvelles règles de bonnes pratiques (suite de BP01–BP07) : définition (`skos:definition` ou `rdfs:comment`), libellés dans les langues du projet (`rdfs:label`/`skos:prefLabel` fr et en), auteur (`dcterms:creator`), source (`dcterms:source`), statut de revue (`vs:term_status` ou équivalent W3C à justifier) ; score de complétude par entité et pour l'ontologie, visible dans Conformité et dans la fiche de l'éditeur ; justification des caractéristiques d'une propriété (annotation `rdfs:comment` dédiée ou `skos:note`, à justifier).
2. **Dépréciation.** `owl:deprecated true` + remplaçant (`dcterms:isReplacedBy`) : marqué dans l'éditeur et les listes, constat dans l'analyse (une entité dépréciée n'est pas générée par défaut, arbitrage proposé), ligne dans le rapport de transposition ; action « Déprécier » au lieu de supprimer.
3. **Version sémantique.** `owl:versionInfo` au format SemVer et `owl:versionIRI` sans version dans l'espace de noms ; à l'enregistrement d'une version de projet, calcul du diff avec la précédente et proposition majeure / mineure / correctif (ajout ou retrait de classe, changement de relation ou d'attribut = majeure ; libellés, définitions = mineure) avec note de version générée.
4. **Métadonnées d'ontologie.** En-tête du projet : titre, version, dates, auteurs, contributeurs, vocabulaires réutilisés, objectif, mots-clés, sources, licence (`dcterms:*`, `owl:Ontology`), éditables et exportés.

## Critères d'acceptation
pytest vert (règles, diff SemVer, dépréciation de bout en bout) ; aller-retour Turtle sans perte ; `npm run build` ; recette `BACKEND_PORT=9149 FRONT_PORT=5149 node tools/recette/l49_bonnes_pratiques.mjs` ; doc fr/en, i18n, help_map, CONTRACTS, skill `w3c-ontology-conformance` et `ontology-rapid-design` mis à jour. Relecteurs : query (SPARQL / diff), shacl, curiosity + neo4j (dépréciation dans les cibles), scout, doc.
