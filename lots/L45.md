Pilote : mobile (appli-mobile). Origine : retour de Jerem du 16/11 sur la version mobile de L44. Rapport : `journal/L45/rapport.md`.

## Objectif
1. Choisir le fournisseur / modèle de langage depuis la feuille Krakie du téléphone, avec le mécanisme du panneau d'ordinateur (`/api/assistant/status`, état `ontoforge.assistant.ui`, `provider_id` des appels) ; aucune clé ni adresse exposée (L40-01, L41).
2. Panneaux repliables sous 700 px : composant commun `Fold` (kit), titre + description repliés, titre seul ouvert, `aria-expanded`, clavier, état par écran dans localStorage.
3. Retirer sous 700 px les raccourcis qui doublonnent la barre d'onglets (carte « Raccourcis » de l'accueil, « Ctrl+K » du bouton Krakie).
