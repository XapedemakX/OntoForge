# L43 : changement de mot de passe pour tous les comptes, corrections L42-01 / 03 / 05

Pilote : lead. Relecteurs : secu (comptes, masque, limiteur, journal), scout (menu du compte, panneau d'administration), doc puis humain. Origine : demande de Jerem du 15/11, D-L43-01 (remplace le point 2 de D-L42-02).

## Objectif
Tout compte connecté change son mot de passe depuis le menu du compte, y compris ceux de `ONTOFORGE_AUTH_USERS` (le nouveau hachage masque celui de la configuration). Les constats L42-01, L42-03 et L42-05 sont corrigés.

## Livrables
1. Masque des comptes de la configuration dans `accounts.json` (changement par le titulaire, réinitialisation et retour à la configuration par un administrateur, avertissement quand la configuration change).
2. Menu du compte : « Changer mon mot de passe » (afficher/masquer, succès, autres sessions coupées), i18n fr / en, aide Krakie (`account-password`, ancre `changer-mon-mot-de-passe`).
3. L42-01 : hachage hors verrou, relecture sous verrou, limiteur `pwd:<login>`. L42-03 : rotation avec archives, échec du journal = échec de l'action. L42-05 : champ `type=password`.
4. Tests, recette, CONTRACTS §17, guide fr / en, limites, API, glossaire, CHANGELOG fr / en, rapport.

## Fichiers
`auth/accounts.py`, `api/{auth,admin}.py`, `assistant/help_map.json`, front `auth/{AccountMenu,auth.css}`, `screens/admin/Admin.tsx`, `api.ts`, `i18n/*`, tests `test_l43_password.py` (et `test_l42_admin.py` adapté), recette `tools/recette/l43_password.mjs`.
