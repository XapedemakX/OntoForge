## Relecture
- shacl relit w3c ; w3c relit shacl : OWA vs CWA (`only` ≠ `sh:class` ; `rdfs:domain` ≠ `sh:targetSubjectsOf` + `sh:class` — inférence vs validation ; `hasKey` ≠ unicité ; inférence SHACL `none` par défaut), documenté dans les deux skills.
