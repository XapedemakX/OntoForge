# L48 : import déterministe SQL DDL, CSV et JSON Schema

Pilote : lead (sous-agent dédié). Origine : carnet d'idées P-07, « lance le tout » de Jerem du 16/11. Rapport : `journal/L48/rapport.md`.

## Objectif
Importer sans LLM, depuis l'écran Projets (zone de dépôt) et l'import du projet :
- **DDL SQL** (`CREATE TABLE`, PostgreSQL / MySQL / SQL Server courants) : table → classe, colonne → propriété de données (types SQL → xsd), clé primaire → `owl:hasKey`, clé étrangère → propriété objet (domaine, portée, cardinalité), table d'association à deux clés étrangères → propriété objet (ou classe réifiée si colonnes en plus), `NOT NULL` → shape SHACL `minCount 1`, `UNIQUE`, `CHECK IN (…)` → énumération.
- **CSV** (en-tête) : une classe nommée d'après le fichier, types déduits d'un échantillon.
- **JSON Schema** : objets → classes, propriétés, `required` → shapes, `$ref` → relations, `enum`.
Aperçu avant application (liste de ce qui sera créé), jamais d'application silencieuse ; rapport des éléments ignorés. Parseur maison borné (taille, profondeur, temps) : aucune nouvelle dépendance.
