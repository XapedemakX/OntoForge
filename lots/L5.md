## Écrans It1 — « charger / voir constats / arbitrer / exporter »
1. **Projets** : liste, créer, « Démarrer depuis un exemple » (*Maintenance automobile* `automaint`, *Ontologie piège* `trap`), supprimer avec confirmation.
2. **Charger** : import fichier (`.ttl .owl .rdf`, shapes), `kind=auto` par défaut, affichage des `warnings` et de `onto.unmapped` ; arbre classes / propriétés en lecture.
3. **Conformité** : profil DL (badge), issues triées par niveau avec `spec_ref` ; validation SHACL d'un fichier de données (résultats `focus / path / constraint / message`).
4. **Constats & arbitrage** : cible Curiosity (défaut) / Neo4j ; trois groupes **Auto** (replié) / **À arbitrer** / **Perdu** ; options (`label`, `impact`), recommandation mise en avant, choix → `PUT /decisions/{target}` ; « Accepter toutes les recommandations » ; compteur `summary()` ; décisions orphelines (« stale ») signalées ; `X00` badge « non traité (it1) ».
5. **Exporter** : fichiers générés (`GET /generate/{target}`) en lecture, téléchargement zip, rapport de transposition rendu, export Turtle de l'ontologie et des shapes.
6. **Assistant** (avec L6) : zone de texte → brouillon (`POST /assistant/draft`, `kind=text`) → éléments proposés à cocher (classes, propriétés) → fusion de la sélection côté front puis `PUT /projects/{id}/onto` ; statut du fournisseur (`/assistant/status`).

**It2 (Should)** : éditeur façon Protégé, saisie rapide DSL (CodeMirror), diagramme Cytoscape, génération de shapes, écran Requêtes, assistant CSV / SQL / shapes / explication.
