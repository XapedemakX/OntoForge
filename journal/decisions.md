## D-L48-01 (17/11, lot L48, à confirmer par Jerem) : import déterministe SQL / CSV / JSON Schema
- **Sans IA, aperçu obligatoire.** Le résultat est calculé de façon pure ; l'application le recalcule et refuse (409) si l'empreinte diffère de celle de l'aperçu. Les pertes (index, déclencheurs, `CHECK` complexes, mots-clés JSON Schema) sont listées, jamais silencieuses.
